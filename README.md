# giri-skills

Personal skills and principles for AI-assisted development.

## Structure
- `core/`: General principles and coding philosophies.
- `patterns/`: Architectural patterns (e.g., DDD).
- `stacks/`: Technology-specific guidelines.
- `tools/`: Configuration and scripts for AI tools (Gemini CLI, Claude Code, etc.).

## Usage
Reference these files in your AI tool configurations to maintain a consistent persona and engineering standard.
